# Nomination Form Filler

A browser app that fills the Great Eastern *Appointment / Change of Nominee(s) / Trustee(s)* form (NBZ-FNOMI-V07-082025) from customer details.

- Customer details are processed in the browser only. Nothing is sent to a server.
- The blank nomination form is **not** included. Load your own copy once per device; it is remembered on that device.
- Photo/IC reading downloads a text-recognition engine (Tesseract.js) the first time it is used.

Open the app: see the GitHub Pages link for this repository.
